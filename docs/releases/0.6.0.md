# Elementor JSON Bridge 0.6.0

This release expands the private GitHub bridge from generic WordPress content synchronization into guarded content-and-commerce operations.

## Highlights

- WordPress post/page create, update and confirmed delete requests.
- Real new Elementor document creation through Elementor's registered document manager.
- WooCommerce product CRUD through `WC_Product`, including current stable global identifier, low-stock and brand fields when supported by the installed version.
- WooCommerce product Trash by default and explicit `force=true` permanent delete.
- Variable-product variation CRUD through `WC_Product_Variation`.
- WordPress/WooCommerce taxonomy term CRUD with ACF/Yoast extensions.
- Live `abilities.json` discovery for safe Core, ACF, Yoast SEO and WooCommerce product abilities.
- Full desired-state prevalidation, exact readback and verified rollback for direct updates.
- Request-process locking and idempotent fingerprints.

## Audited current-integration canary

- WordPress 7.1 / PHP 8.3
- Elementor 4.2.4
- ACF 6.8.9 with ACF AI explicitly enabled for the runtime test
- Yoast SEO 28.4
- WooCommerce 11.0.1

A WordPress 6.8.3 / PHP 8.1 compatibility canary remains in the matrix.

## Required production gates

Do not publish/deploy solely from source review. Validate the exact CI-built ZIP on the intended staging site, including the real private GitHub connection, exact plugin/add-on combination, Elementor Pro conditions if applicable, and authenticated browser/accessibility behavior.
